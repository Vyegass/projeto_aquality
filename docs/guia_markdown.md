=====================================================
GUIA RÁPIDO DE FORMATAÇÃO (MARKDOWN) - PROJETO AQUALITY
=====================================================

1. TÍTULOS (HIERARQUIA)
   Use a hashtag (#) seguida de um espaço.
   # Título Principal (H1)
   ## Seção Principal (H2)
   ### Subtópico (H3)
   #### Detalhes Técnicos (H4)

2. ENFASE NO TEXTO

   **Negrito** -> Use dois asteriscos: **texto**

   *Itálico* -> Use um asterisco: *texto*
   
   ***Destaque*** -> Use três asteriscos: ***texto*** 

3. LISTAS E ORGANIZAÇÃO
   - Lista de pontos: Use um hífen (-) e espaço.
   1. Lista numerada: Use o número, ponto e espaço.
   ---  -> Três hífens criam uma linha divisória.

4. CÓDIGOS (ESSENCIAL PARA ESTUDOS)
   Crase única ( ` )  -> Para comandos no meio da frase.
   Exemplo: Use o comando `print()`.

   Três crases ( ``` ) -> Para blocos de código inteiros.
   Exemplo:
   ```python
   import pandas as pd
   df = pd.DataFrame(dados)
