# Projeto Aquality - Controle de Vendas Automático

Este projeto nasceu da necessidade de otimizar o fluxo de vendas na minha empresa e serve como meu laboratório de estudos em programação e automação.

## Objetivo
Desenvolver uma ferramenta que automatize o registro de pedidos. A ideia central é que o sistema consiga interpretar conversas de WhatsApp e registrar os pedidos automaticamente em um controle de vendas.

## Status do Projeto
- [x] Início do repositório e documentação básica.
- [ ] Definição das tecnologias (Linguagem, Banco de Dados).
- [ ] Estudo de integração com API do WhatsApp.
- [ ] MVP (Mínimo Produto Viável) do registro de vendas.

## 🧠 Aprendizados e Desafios
Como iniciante, este projeto focará em:
* Versionamento de código com **Git e GitHub**.
* Lógica de programação aplicada a negócios.
* Integração de sistemas (WhatsApp -> Controle de Vendas).
